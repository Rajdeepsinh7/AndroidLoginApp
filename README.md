# Android Login App (Java)

A simple Android Login Application built using **Kotlin (KT)** and **XML**.  
This project is designed for beginners who are learning Android app development.

---

## 📱 Features
- Login screen with Username & Password
- Input validation
- Simple and clean UI
- Beginner-friendly Kotlin code

---

## 🛠️ Tech Stack
- **Language:** Java (java)
- **UI:** XML
- **IDE:** Android Studio
- **Platform:** Android
